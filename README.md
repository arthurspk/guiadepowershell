## :dart: O guia para alavancar a sua carreira

> PowerShell é a linguagem de automação e o shell padrão da Microsoft — usado para administrar Windows, Azure, Microsoft 365 e, hoje, também Linux e macOS. Se o seu trabalho envolve manter servidores no ar, provisionar nuvem ou automatizar tarefas repetitivas em ambiente Windows, é quase certo que o PowerShell vai aparecer no seu caminho. Este guia reúne documentação oficial, cursos, livros, ferramentas, comunidades e um capítulo sobre como usar IA a favor da sua produtividade com PowerShell — tudo verificado e organizado para quem está começando ou quer sair do "copiar e colar comando" para escrever scripts de verdade.

## 🗺️ Roadmap

Não existe um roadmap visual único e oficial para PowerShell (como há para outras linguagens). O caminho mais direto é: instale o PowerShell 7, leia o livro gratuito **PowerShell 101**, pratique o pipeline e a sintaxe com os "Deep Dives" oficiais e, só depois, avance para módulos, testes com Pester e automação com DSC.

- [PowerShell 101 — Introduction](https://learn.microsoft.com/en-us/powershell/scripting/learn/ps101/00-introduction) — Livro introdutório oficial e gratuito de Mike F. Robbins, hospedado no Microsoft Learn: por onde começar do zero.
- [Referência de comandos PowerShell (SS64)](https://ss64.com/ps/) — Folha de referência não oficial, mas clássica, com todos os cmdlets principais organizados por categoria — ótima para consulta rápida enquanto você aprende.
- [Módulos e cmdlets — índice oficial](https://learn.microsoft.com/en-us/powershell/module/) — Índice de todos os módulos e cmdlets documentados oficialmente; use para descobrir o que existe antes de escrever sua própria função.

## 🤖 IA na prática

PowerShell trabalha com **objetos**, não com texto — então uma sugestão de IA que "parece certa" pode devolver o tipo errado de objeto e quebrar o próximo cmdlet do pipeline. Use isso a seu favor: peça, mas sempre confira o que voltou.

**Para aprender**
- Cole um erro em vermelho no console (ex.: `The term 'xyz' is not recognized...`) e peça para explicar a causa e sugerir a correção.
- Peça para **converter um script `.bat` ou `.vbs` antigo para PowerShell**, explicando cada linha.
- Peça um one-liner complexo com vários `|` "explicado passo a passo, cmdlet por cmdlet".
- Peça **exercícios com gabarito** sobre o tópico que está estudando (pipeline, hashtables, funções).

**Para trabalhar**
- Use o Copilot integrado à extensão de PowerShell do VS Code, o Cursor ou o Claude Code para: gerar funções com `[CmdletBinding()]` e ajuda completa, escrever testes Pester, e converter scripts de administração manual em automações reutilizáveis.
- Depois de **cada** sugestão aceita, rode o script com `-WhatIf` (quando o cmdlet suportar) antes de executar de verdade — principalmente em produção.
- Nunca execute, sem revisar, um script gerado por IA que mude permissões, apague dados ou rode com credenciais elevadas.

**Ferramentas de IA para PowerShell**

- [GitHub Copilot](https://github.com/features/copilot) — Autocompletar e chat com IA no editor; entende o contexto do seu script e sugere cmdlets e parâmetros.
- [Copilot na extensão de PowerShell do VS Code](https://learn.microsoft.com/en-us/powershell/scripting/dev-cross-plat/vscode/using-vscode#github-copilot-in-visual-studio-code) — Seção oficial da documentação mostrando como o Copilot se integra à extensão de PowerShell, com sugestões cientes do console integrado.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: refatora scripts, explica pipelines complexos e escreve testes Pester.
- [Microsoft Copilot no Azure](https://learn.microsoft.com/en-us/azure/copilot/overview) — Assistente de IA integrado ao portal do Azure que ajuda a gerar e explicar comandos do módulo Az PowerShell.
- [AIShell (arquivado)](https://github.com/PowerShell/AIShell) — Projeto da própria equipe do PowerShell que trazia um assistente de IA integrado ao console; foi descontinuado em janeiro de 2026, mas o código segue disponível como referência de como a Microsoft desenhou essa integração.

## 🎓 Certificações

Não existe uma certificação chamada apenas "PowerShell" — a habilidade é cobrada dentro de certificações mais amplas de administração Microsoft. As três abaixo são as que mais avaliam automação com PowerShell na prática.

- [MS-102: Microsoft 365 Administrator](https://learn.microsoft.com/en-us/certifications/exams/ms-102) — Exame da Microsoft que cobra automação de tarefas administrativas com PowerShell no Microsoft 365.
- [AZ-104: Microsoft Azure Administrator](https://learn.microsoft.com/en-us/certifications/exams/az-104) — Certificação de administrador Azure; usar o módulo Az PowerShell é parte do conteúdo cobrado.
- [Windows Server Hybrid Administrator Associate](https://learn.microsoft.com/en-us/certifications/windows-server-hybrid-administrator/) — Certificação de administração híbrida de Windows Server, com automação via PowerShell como habilidade central.

- [Hey, Scripting Guy! (arquivo oficial)](https://devblogs.microsoft.com/scripting/) — Arquivo do clássico blog de scripting da Microsoft, com milhares de artigos práticos acumulados ao longo dos anos.
- [Adam the Automator](https://adamtheautomator.com/) — Um dos blogs mais lidos sobre PowerShell e automação de TI, com tutoriais extensos e atualizados.
- [jdhitsolutions (Jeff Hicks)](https://jdhitsolutions.com/blog/) — Blog de Jeff Hicks, MVP e coautor de vários livros de PowerShell, com posts técnicos frequentes.
- [Arcane Code (Robert Cain)](https://arcanecode.com/) — Blog de Robert Cain com uma longa série dedicada inteiramente a PowerShell.
- [Mike F. Robbins](https://mikefrobbins.com/) — Blog do autor do PowerShell 101, hoje redator técnico do Azure PowerShell na Microsoft.
- [PowerShell Explained (Kevin Marquette)](https://powershellexplained.com/) — Artigos aprofundados sobre tópicos específicos da linguagem, muito citados pela comunidade.
- [OverPoweredShell](https://overpoweredshell.com/) — Blog de David Christian com foco em automação em nuvem (AWS/Azure), DSC e desenvolvimento de módulos.
- [netnerds.net (Chrissy LeMaire)](https://blog.netnerds.net/) — Blog da criadora do módulo dbatools (MVP de PowerShell e SQL Server), com posts recentes sobre IA aplicada à automação.
- [xkln.net](https://xkln.net/) — Blog de infraestrutura e nuvem com vários artigos técnicos sobre PowerShell aplicado a Azure e redes.
- [DEV Community — tag PowerShell](https://dev.to/t/powershell) — Artigos da comunidade sobre PowerShell, publicados por desenvolvedores do mundo todo.
